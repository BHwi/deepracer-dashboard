        iteration별 기록
        
            
        
            
        DRfC 의 지표 파일에는 iteration 번호가 없어서, 학습 에피소드를 정책 갱신 간격(20개)씩 묶어 환산한 값입니다.
        
          
        
        
        
        
        로그
        
        
        
          
        
          
          
          
        
        
        
        
        
        이 실험의 설정
        
      
        
    
        

    
    
        
      
        
      
        
        
        
        
        학습한 모델을 학습 없이 달려 평가합니다. DRfC 는 한 번에 하나(학습 또는 평가)만 실행하므로 학습을 먼저 중지하세요.
        
        
        
          
          
          
          
          
          
          
          
          
        
        
        
        주행 영상 저장을 켜고 평가하면 평가가 끝난 뒤 영상이 저장소(모델/mp4/)에 만들어지고, 아래 평가 기록에서 평가 이름을 눌러 볼 수 있습니다. 켜지 않고 한 평가에는 영상이 없습니다 (DRfC 의 기본값은 저장 안 함입니다). 이름은 비워 두면 평가 시각으로 표시되고, 나중에 붙이거나 바꿀 수도 있습니다.
        
        
        '복사본으로 평가'는 모델 폴더를 새 이름으로 복사한 뒤 평가해서 원본에 평가 기록이 섞이지 않게 합니다 (DRfC 의 -c 옵션).
        
        
        
        
        
        
        평가 기록
        
        
        
      
        
    
        

    
    
        
      
        
      
        
        
        
        
        실물 DeepRacer 차량에 올릴 파일(agent/model.pb 와 model_metadata.json 이 든 tar.gz)을 만듭니다. DRfC 의 dr-create-car-zip 을 사용하며 학습 컨테이너가 꺼져 있어도 만들 수 있습니다.
        
        
        
          
          
        
        
        
        
        
        만들어진 파일
        
        
        
        
        차량에 올리는 방법은 쓰고 있는 차량 소프트웨어(공식 펌웨어 또는 자체 관리형 솔루션)의 안내를 따르세요. 시뮬레이션과 실제 환경은 조명, 노면, 카메라가 달라서 성능이 다를 수 있습니다.
        
      
        
    
        

    
    
        
      
        실험 정리
        
      
        MiniRacer 실험 기록(runs/ 폴더의 학습 로그, 모델, 리포트)을 삭제합니다. 되돌릴 수 없습니다. 학습 중인 실험은 지울 수 없습니다.

      읽기 는 조회만, 변경 은 설정이나 실행 상태를 바꾸고, 주의 는 영향이 커서 확인을 한 번 더 받습니다. 학습·평가 시작은 각 화면에서 합니다.
